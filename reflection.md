\## Exercise 1: Personal Portfolio Conflict Simulation

\## Exercise 2: Recipe Bug Hunt with Git Bisect



\### 1. How did you find the bug?

&#x09;Git test commits between a known-good and a known-bad commit.



\### 2. How many tests for 100 or 1,000 commits?

&#x09;Probably 10 tests. 



\### 3. How is Bisect better than checking every commit?

&#x09;It uses binary search to reduce the number of commits that need testing.



\### 4. When is Bisect useful?

&#x09;Bisect is useful when a bug appears in a project with many commits.



\### 5. What does Bisect need?

&#x09;1 known-good commit and 1 known-bad commit.
